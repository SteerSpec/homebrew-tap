# Contributing

Thanks for helping improve the SteerSpec tap.

## Setup

```bash
make install-hooks   # validates commit messages locally
```

## Commits and pull requests

- Use [Conventional Commits](https://www.conventionalcommits.org/): `<type>(<scope>): <description>`
  (`feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, `revert`).
- Open a pull request against `main`; direct pushes are blocked. The PR title must also be a
  Conventional Commit, since it becomes the squash commit that release-please reads.
- Versions follow semver: `fix` is a patch, `feat` a minor, and a breaking change (`!` or a
  `BREAKING CHANGE:` footer) a major.

## Casks

`Casks/strspc.rb` is generated by GoReleaser from strspc-CLI; do not edit it by hand.
Before changing any cask or cask-related workflow, run:

```bash
brew style Casks/
brew audit --cask --online SteerSpec/tap/strspc
```

## Work tracking

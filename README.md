[Homebrew](https://brew.sh) tap for [SteerSpec](https://steerspec.dev) tools.

## Available casks

| Cask | Description | Source |
|------|-------------|--------|
| `strspc` | CLI for SteerSpec: render, validate and manage behavioral rule files | [strspc-CLI](https://github.com/SteerSpec/strspc-CLI) |

> The `strspc` cask is being added; it appears here after the first CLI release publishes to this tap.

## Install

```bash
brew install --cask SteerSpec/tap/strspc
```

Or tap first, then install by name:

```bash
brew tap SteerSpec/tap
brew install --cask strspc
```

Upgrade and uninstall:

```bash
brew upgrade --cask strspc
brew uninstall --cask strspc
```

### Notes

- **macOS only.** On Linux, download the tarball from the
  [strspc-CLI releases](https://github.com/SteerSpec/strspc-CLI/releases).
- **Unsigned binaries.** The cask clears the macOS quarantine flag on install so Gatekeeper
  does not block `strspc`.

## How it is maintained

Casks in `Casks/` are generated by GoReleaser from
[strspc-CLI](https://github.com/SteerSpec/strspc-CLI) on each release. Do not edit them by hand;
change the `homebrew_casks` section of that repo's `.goreleaser.yml` instead.

Tap releases (workflow and tooling changes) follow [Semantic Versioning](https://semver.org)
via [release-please](https://github.com/googleapis/release-please), independent of the `strspc`
version in the cask.

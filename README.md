[Homebrew](https://brew.sh) tap for [SteerSpec](https://steerspec.dev) tools, for engineers who install the `strspc` CLI on macOS or Linux.

The `strspc` cask pins a release version and a SHA-256 checksum per architecture, and downloads the
tarball from a tagged [strspc-CLI release](https://github.com/SteerSpec/strspc-CLI/releases). See
[the cask at commit `e1f1541`](https://github.com/SteerSpec/homebrew-tap/blob/e1f1541d6753c42fd44ed2ed03386d93c63777bb/Casks/strspc.rb),
which pins `strspc` v1.36.0 as of that commit. The macOS binaries are notarized; the Linux and
Windows binaries are not. See [Notes](#notes).

## Install

```bash
brew tap SteerSpec/tap
brew trust --cask steerspec/tap/strspc
brew install --cask strspc
```

Recent Homebrew versions refuse to load casks from untrusted taps
(`Refusing to load cask steerspec/tap/strspc from untrusted tap`), so the `brew trust` step is
required once. It trusts only the `strspc` cask; `brew trust steerspec/tap` trusts the whole tap,
including future casks. See [Tap Trust](https://docs.brew.sh/Tap-Trust).

Upgrade and uninstall:

```bash
brew upgrade --cask strspc
brew uninstall --cask strspc
```

### Notes

- **macOS and Linux.** The cask installs `strspc` on both, for arm64 and amd64. Homebrew does not
  support Windows; download the `windows_amd64` or `windows_arm64` zip from the
  [strspc-CLI releases](https://github.com/SteerSpec/strspc-CLI/releases).
- **Notarization.** Only the macOS binaries are notarized. The Linux and Windows binaries are not
  signed or notarized.

## How it is maintained

Casks in `Casks/` are generated by GoReleaser from
[strspc-CLI](https://github.com/SteerSpec/strspc-CLI) on each release. Do not edit them by hand;
change the `homebrew_casks` section of that repo's `.goreleaser.yml` instead.

Tap releases (workflow and tooling changes) follow [Semantic Versioning](https://semver.org)
via [release-please](https://github.com/googleapis/release-please), independent of the `strspc`
version in the cask.

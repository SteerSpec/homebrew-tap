# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/SteerSpec/homebrew-tap/security/advisories/new).
Do not open a public issue.

In scope: cask integrity (URLs, checksums), install/uninstall hooks, and the workflows in
this repository. Vulnerabilities in the `strspc` CLI itself belong in
[strspc-CLI](https://github.com/SteerSpec/strspc-CLI/security/advisories/new).

We aim to acknowledge reports within a few working days.

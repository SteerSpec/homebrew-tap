# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith, and keep discussion focused on the work.

To report unacceptable behavior, use
[GitHub's private reporting](https://github.com/SteerSpec/homebrew-tap/security/advisories/new)
or contact a maintainer directly.
